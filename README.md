## Overview

This project contains an SSD1357 display driver adapted for the STM32F407 microcontroller.

The implementation is based on [cos-public/ssd1357](https://github.com/cos-public/ssd1357) and was created for rapid hardware testing and display validation. 
It is functional in its current form, but additional refactoring and encapsulation are still required for a more robust and maintainable design.
